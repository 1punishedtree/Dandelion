# CLAUDE.md

Project-local instructions for working in this repository (overrides global config where they conflict).

## Project

`pg` (PasswordGenerator) is a native SwiftUI app targeting iOS and macOS. See `README.md` for structure and build instructions.

## Working conventions

- The Xcode project (`PasswordGenerator.xcodeproj`) is generated by XcodeGen from `project.yml`. Never hand-edit the `.xcodeproj`; change `project.yml` and re-run `xcodegen generate`.
- Source files live under `PasswordGenerator/{App,Models,Views}`; both the iOS and macOS targets share the same source folder.
- `xcodebuild` on this machine currently cannot load `IDESimulatorFoundation` (broken system Xcode component, needs `sudo xcodebuild -runFirstLaunch` to fix). Until fixed, verify Swift changes with `swiftc -typecheck` against the relevant SDK (see README) instead of `xcodebuild build`.
