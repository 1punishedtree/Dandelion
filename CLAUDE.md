# CLAUDE.md

Project-local instructions for working in this repository.

## Project

`Dandelion` is a native SwiftUI password generator for iOS and macOS. Its app display name is `random`. See `README.md` for structure and build instructions.

## Working conventions

- The Xcode project (`Dandelion.xcodeproj`) is generated by XcodeGen from `project.yml`. Never hand-edit the `.xcodeproj`; change `project.yml` and re-run `xcodegen generate`.
- Source files live under `Dandelion/{App,Models,Views}`; both the iOS and macOS targets share the same source folder.
- Build with Xcode or `xcodebuild`; use the `Dandelion-iOS` and `Dandelion-macOS` schemes.
